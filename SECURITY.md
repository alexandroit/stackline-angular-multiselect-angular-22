# Security Policy

## Scope

This repository is the maintained Angular 22 playground for
`@stackline/angular-multiselect-dropdown`. Vulnerabilities in the package itself
should be reported to the
[canonical package repository](https://github.com/alexandroit/angular-multiselect-dropdown/security/advisories/new).
Issues that are specific to this playground remain in scope here.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/alexandroit/stackline-angular-multiselect-angular-22/security/advisories/new).
Do not disclose exploit details in a public issue. Include a minimal synthetic
reproduction, affected route, browser and Node.js versions, and realistic impact.
